1. คำนวณพื้นที่วงกลม

START

INPUT radius

SET PI = 3.14159

area = PI × radius × radius

DISPLAY area

END

2. คำนวณเกรด

START

INPUT score

IF score >= 80
    Grade = A

ELSE IF score >= 70
    Grade = B

ELSE IF score >= 60
    Grade = C

ELSE IF score >= 50
    Grade = D

ELSE
    Grade = F

DISPLAY Grade

END

3. หาค่าสูงสุดของตัวเลข 3 จำนวน

START

INPUT num1
INPUT num2
INPUT num3

max = num1

IF num2 > max
    max = num2

IF num3 > max
    max = num3

DISPLAY max

END
